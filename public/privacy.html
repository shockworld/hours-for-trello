Privacy

Hours for Trello stores work date, time duration, a brief description, Trello member identity, board and card IDs, and card name. The application requires a Trello server token to validate board membership and card ownership. It does not request users' Trello passwords.

Members of a given Trello board can view work logs on that board, including guests. Only configured team members can create work logs and edit or delete their own entries. Data is not sold or used for advertising.

The operator controls hosting, data retention, backup and deletion. Ask the operator to export or delete your board's work history. The hosting environment and operator contact should be documented before public distribution.
